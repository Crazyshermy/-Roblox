# Archived: RBXOS design (superseded)

This was the earlier architecture for a daemon, MCP gateway and Studio companion plugin. No code was ever written. It has been superseded by Roblox Apex, a skill layer (see `../../README.md`).
Its reasoning concepts were extracted into the skills: evidence grades, Reality Check, Boundary Breaker, the barrier catalog, anti-slop verdicts, the feel timeline, fuzz strategies, differential diagnosis and ADR decisions. The research notes in `01-research-findings.md` remain a useful reference for Studio plugin and Open Cloud capabilities if tooling is ever built.
