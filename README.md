# RBXOS: a Roblox development environment for Claude Code

RBXOS is a design for a `/roblox` environment that makes Claude Code a far more capable Roblox development agent. It does not restrict Claude in any way. Claude remains the reasoning engine. RBXOS adds:

- **Memory:** a Project Brain, settled decisions, and a project constitution.
- **Senses:** Roblox's built-in Studio MCP server behind a policy gateway, plus a companion Studio plugin for multi-client tests, profilers, captures, and runtime taps.
- **Hands with an undo button:** changesets and checkpoints that cover both files and the Studio DataModel.
- **An epistemology:** evidence grades, pre-registered experiments, knowledge claims re-verified by probes, and critics that must cite evidence.

**Status:** architecture and implementation plan. No code yet.
