# Player-behavior hypotheses (not psychology)

**Epistemic status:** these are *working variables for reasoning*, informed by player-motivation research and design practice (E2–E3). They are **not** validated numerical models. Never present predictions from them as facts. Real-player data (analytics, playtests, interviews) always overrides them.

## Variables (use the ones that matter for the question)
| Variable | Observable signs in play | Design levers |
|---|---|---|
| Curiosity / novelty seeking | leaves the path, opens doors, tries unknown affordances | secrets, partial information, visual hooks, mysteries |
| Exploration | path variety, visits optional areas | landmarks, rewards for detours, verticality |
| Mastery | retries after failure, chooses harder options | skill ceilings, clear failure feedback, optional challenges |
| Competition | checks ranks, seeks PvP, compares | fair matchmaking, readable skill expression, spectating |
| Cooperation | stays near friends, helps, revives | interdependent roles, shared goals, rescue mechanics |
| Collection | completes sets, checks counters | visible sets, meaningful collectibles (not filler) |
| Creativity / expression | customizes, builds, decorates | building tools, cosmetics, showcases |
| Social motivation | follows friends, chats, emotes | proximity play, shared spaces, social status signals |
| Risk tolerance | picks gambles over safe options | risk/reward choices, push-your-luck loops |
| Patience / grind tolerance | repeats non-novel loops before leaving | pacing, novelty cadence, shortcuts |
| Complexity tolerance | handles several new affordances at once | progressive disclosure, onboarding sequencing |
| Attention / quit threshold | time without perceived progress before leaving | early wins, clear goals, the first-minute hook |

## How to use
1. Name the **behavior you expect** and *which* variable drives it ("explorers will find the vent route; low-patience players won't").
2. Name what you'd **observe** if you're wrong.
3. Prefer **segments** over "the player": different motivations want different things, so check that a change helping one segment doesn't break another (e.g. faster solo rewards may reduce grouping).
4. When real data exists (funnels, retention, session length, heatmaps, recordings), reason from it first.

## Evidence ladder for player claims
real controlled experiment (A/B) > real-player analytics or observation > moderated playtest > designer intuition with a stated mechanism > simulated or AI "player" reasoning. AI personas and bots can find **reachability, confusion points and exploits**. They cannot measure fun.
